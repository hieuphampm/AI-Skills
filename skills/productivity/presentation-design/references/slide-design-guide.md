# Slide Design Guide

Consult this reference during Steps 2–4 of `presentation-design`.

## 1. Deck Structure
- **Title slide**: Talk title, subtitle, presenter, date.
- **Agenda**: 3–5 bullets previewing the flow.
- **One idea per slide**: Each slide makes a single point; the title is the takeaway, not a label.
- **Summary**: Recap the 2–3 key takeaways.
- **Call to action / Q&A**: End with a specific next step or a prompt for questions.

## 2. Content Density (6x6 Rule)
- Max **6 bullets** per slide and **~6 words** per bullet.
- Prefer short phrases over full sentences.
- If a slide exceeds this, split it into two slides.

## 3. Visual Hierarchy
- **Title** is the largest text; it should state the takeaway.
- Use **consistent** font sizes: title > subtitle > body.
- Leave whitespace; avoid cramming.
- Use charts/images to replace walls of text when data supports it.

## 4. Theming
- **Colors**: Pick one primary + one accent; keep contrast high for readability.
- **Fonts**: One font family for headings, one for body (or a single family with weight variation).
- **Default theme** (if none provided): dark text on white, one accent color (e.g., `#2563EB`), sans-serif.
- Apply the theme consistently across every slide.

## 5. Speaker Notes
- Write 2–4 sentences per slide explaining what to say and why.
- Notes make the deck presentable, not just readable — the slide shows the point, the notes carry the story.
